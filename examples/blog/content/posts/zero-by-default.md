---
title: Zero by default
date: 2026-09-02
summary: A page with nothing to run should download nothing to run it.
---

The runtime is a quarter of a megabyte, and for an application that is the right trade:
the runtime *is* the application. For an article it is the wrong one, and it was the trade
every page made until islands existed.

> A page that mounts nothing interactive ships no runtime.

Everything you are reading was written once, at build time, by CPython — the Markdown was
rendered there, the front matter was checked there, and none of it is in the page you
downloaded.
