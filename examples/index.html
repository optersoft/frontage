Frontage examples

Each page loads frontage's own Python runtime compiled to WebAssembly and the framework as precompiled bytecode. The source is the same files the browser suite tests.

  • Hello: the package imports, a signal, a store
  • Counter: signals, a memo, holes, a class toggle
  • Todo: a store, For with keys, Show, two-way binding
  • Rows: the js-framework-benchmark table, with timings
  • Fetch: Resource, Loading, Errored
  • Forms: bindings, Switch, an Action on submit
  • Template: the counter as a template string, html(t"…")
  • Contacts: the router, nested routes, A links, query(); ?mode=history for pushState
  • Wasm library: a C or Rust library compiled to WebAssembly, imported like any Python module
  • Chart: uPlot wrapped as a component — a dashboard with a live 20,000-point chart
  • Weather: Streamlit's Seattle Weather demo, ported — metrics, five charts and a table over 1,461 rows the page ships with it
  • Uber NYC: Streamlit's flagship demo, rebuilt — a million real pickups, an hour slider, and a map whose viewport is an input the histogram reads
  • Locales (examples/locales): the same page tree in English, Spanish and Catalan — pages/[lang]/blog/[slug].py has two parameters, the default language has no URL segment, and the switcher is plain links because the build knows every URL. Twelve pages, and not one of them fetches a runtime. frontage site examples/locales
  • Site (examples/site): a whole site rather than a page — pages/ as the site map, one page per post from static_paths(), a layout, a sitemap and a robots.txt as endpoints, and one island on the one post that needs it. It has no single page to link to here; run it with frontage serve examples/site --prerender or build it with frontage site examples/site
  • Blog: three posts read from disk, front matter checked by frontage.schema, Markdown rendered at build time — and one ::: island container in a post's prose. Needs pip install "frontage[content]"; build it with frontage prerender, or serve it with frontage serve --prerender
  • Islands: a page that ships no runtime, and two islands that ask for one — mount(page, "#app", when="never") and island(view, when="idle"|"visible"). Under this dev server everything is live at once; the deferral only exists in a frontage prerender build
  • Tracker: the whole framework in one app — routes, a store, Optimistic, a Portal modal, an ActionForm
